Project Name:

FitLog

Short Description:

FitLog is a simple workout website. Here user can see workouts, add workout to plan, save workout and see workout details.

Technologies Used:

1 Next.js
2 React toastify
3 TypeScript
4 Tailwind CSS
5 DaisyUI
6 React Icons / Lucide Icons

5 Key Features:

1. User can see different workouts.
2. User can see workout details.
3. User can add workout to My Plan.
4. User can save workout for later.
5. User can sort workouts by Duration, Calories and Rating.
